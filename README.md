# Фатин квест

Персональный медицинский квест в Telegram Mini App: бросание скальпелей во вращающиеся цели, УЗИ, СЛР и другие мини-игры.

## Состав

- `webapp/` — статическое мини-приложение: HTML, CSS, JavaScript, изображения и синтезируемый звук.
- `bot/bot.py` — Telegram-бот на стандартной библиотеке Python, long polling и кнопка запуска приложения.
- `bot/fatya-bot.service` — пример службы systemd с внешним файлом окружения.
- `bot/env.example` — шаблон настроек без токена и реквизитов сервера.
- `tools/make_us.py` — подготовка УЗИ-изображений; нужен Pillow.
- Изображения в корне — исходные материалы для квеста.

## Локальный просмотр

Из корня проекта:

```sh
python -m http.server 8080 --directory webapp
```

Откройте `http://localhost:8080`. Для запуска внутри Telegram разместите содержимое `webapp/` на HTTPS-хостинге и укажите адрес в `WEBAPP_URL`.

## Бот

Требуется Python 3. Бот читает две переменные окружения: `BOT_TOKEN` и `WEBAPP_URL`. Задайте их локально или через конфигурацию службы перед запуском:

```sh
python bot/bot.py
```

Сам скрипт не загружает `.env` автоматически. В Linux пример службы читает внешний файл `/opt/fatya-bot/env`; разместите там локально заполненный вариант `bot/env.example`, ограничьте доступ к нему и при необходимости измените пути службы. Адрес, логин и пароль сервера в проект не входят.

Токены, файлы окружения, приватные ключи и журналы исключены через `.gitignore`. В репозиторий добавляются только шаблоны без секретов. Не вставляйте токен бота в JavaScript мини-приложения.
